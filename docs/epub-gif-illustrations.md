# GIF illustrations in EPUB

Reader displays GIF87a and GIF89a artwork in the reading page, at the size requested by the book. A long press opens the original image for inspection and zoom. A link to a GIF opens the same inspector. Exiting returns to the same text position. A publisher-declared GIF can also appear as the book cover. [Reader simulator capture](screenshots/epub-gif-illustration.png)

The image size comes from the GIF’s logical canvas. The decoder uses the first frame, handles interlacing and the frame’s offset, selects its local or global color table and composites transparent pixels onto paper. Inside inline or packaged SVG, transparent pixels expose the vector drawing underneath. Both reading paths resample the same decoded image for the viewport. A dark reading theme continues to use the book’s image rendering settings. [Frame decoder](../src/gif_image.rs) · [Page layout and full-size view](../src/parley_layout.rs) · [Embedded SVG handling](../src/svg_image.rs)

An EPUB image resource has an 8 MiB compressed-input ceiling. A declared raster cover has a 4 MiB ceiling. A logical canvas may contain up to 8,388,608 pixels, with each side at most 4,096 pixels. The page retains bounded grayscale previews. SVG has a separate budget of up to eight local raster resources, 8 MiB of input and intermediate encoded images, and a maximum rendered viewport of 2,048 pixels per side and 2,097,152 pixels in total. [EPUB resource limits](../src/epub.rs) · [Image budgets](../src/parley_layout.rs) · [SVG limits](../src/svg_image.rs)

KOReader’s CREngine recognizes GIF in document content. Its long-press handler requests the original image at the pressed position and its inspector uses giflib. For an animated file KOReader can also step through subsequent frames. Reader currently displays the first frame on both the page and in the inspector. [CREngine GIF implementation](https://github.com/koreader/crengine/blob/b32a88ffbbf505cf2ea5208c1a49002d70d3609f/crengine/src/lvimg.cpp) · [KOReader long press](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/apps/reader/modules/readerhighlight.lua#L1656-L1673) · [KOReader GIF inspection](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/ui/renderimage.lua#L144-L210)

## Verification

The three affected original EPUBs contain 82 GIFs, including 61 GIF87a and 21 GIF89a resources. All 82 have a single frame. On the Mac, Reader matched independently decoded grayscale pixels at the full intrinsic size of every image. The 80 directly referenced illustrations occupied reading positions in 26 sections. Two other declared GIFs had no reference in book content. In each original, a simulated picker tap opened the book, a long press opened an image and closing the inspector restored the exact previous reading pixels, anchor and navigation history. [Independent Pillow reference generator](../scripts/epub-gif-reference.py) · [Reader workflow check](../src/app/epub_gif_tests.rs)

The authored fixture covers a linked full-size GIF, a GIF cover, a two-frame image and transparent artwork inside inline and packaged SVG. Earlier comic tests exercise misplaced frames, invalid canvas dimensions, first-frame selection and local palettes. [Fixture source](../scripts/generate-gif-epub.py) · [GIF conversion and integration tests](../src/app/epub_gif_tests.rs) · [Comic image tests](../src/comic.rs)

A whole-book comparison covered all 89 sections. Reader originally decoded 67 of the 147 graphic placements. With GIF support it decoded all 147, including the other image formats, and resolved all 1,305 page anchors exactly.

On a Kindle Oasis 3, three native Reader runs and three installed KOReader comparisons completed in 37 seconds. KOReader retrieved the package resources through CREngine, decoded them through the giflib provider used by its image inspector and matched all 82 independent first-frame pixel digests. Touch coordinates on each of three rendered KOReader pages returned the expected original resource bytes. PrimitiveOS Reader also matched all 82 digests and restored the same reading pixels after closing each inspector. The original EPUBs, Reader library and Browser session retained their checksums. The temporary profiles, cache and executable were removed. [Installed KOReader comparison](../scripts/koreader-gif-check.lua) · [Native Reader verification](../src/app/epub_gif_tests.rs)
