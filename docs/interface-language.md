# Reader interface language

Reader offers **English** and **Tiếng Việt (partial)** under Reading controls → Interface language, also available from the reading view's Settings group. English is the default. The choice is saved in Reader's reading controls, separately from each book's language, typography, lookup, text, and stored position. Missing or unknown locale choices fall back to English. Switching the setting does not reopen or repaginate a document. Vietnamese now also translates fixed headers across Reader screens, including library, reading controls, profiles, search, annotation, dictionary, export, archive, statistics, and chooser screens. Dynamic book titles and user-provided names remain unchanged.

The Vietnamese option translates reading-bar shortcuts; menu and configuration labels; selection, dictionary and annotation controls; library and book-management screens; export and reading-data workflows; numeric-editor labels; and fixed screen headers throughout Reader. Menu search recognizes English and Vietnamese for translated menu actions. Translation is allowlisted: document text, selected quotations, book metadata, user-defined values, and dynamic or provider-generated messages remain untouched. Many descriptive messages, generated statistics dates and counts, less common editor text, dynamic status labels, and accessibility text remain English, so Vietnamese is still partial. These translations are authored for Reader; KOReader catalog strings are not copied.

KOReader's [language list and language-change behavior](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/language.lua#L1) are the reference. Vietnamese remains partial: some runtime notices, generated date/number text, and less common editor details stay in English. The other interface locales, plural/number/date handling, right-to-left mirroring, font fallback, and small-screen text-fit review remain open. The frozen screenshot control inventory records its original observations and is not a current completion claim.

The UI uses the existing shared list, icons, and reading bars; no new gesture or screen geometry is introduced. Validate language persistence, fallback from unknown values, navigation/exit, glyph coverage, text fit, dark mode, and portrait/landscape before release. No device, screenshot, or behavioral validation was performed for this increment.
