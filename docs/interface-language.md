# Reader interface language

Reader offers **English** and **Tiếng Việt (partial)** under Reading controls → Interface language, also available from the reading view's Settings group. English is the default. The choice is saved in Reader's reading controls, separately from each book's language, typography, lookup, text, and stored position. Missing or unknown locale choices fall back to English. Switching the setting does not reopen or repaginate a document.

The Vietnamese option currently translates the reading top and bottom bar shortcuts, group and bottom-section headings, the top Navigation, Search and Library groups, allowlisted action titles in the top Appearance, Settings and Tools groups, allowlisted labels in the bottom configuration panels, the Pages action grid, menu-search group and section breadcrumb labels, the selected-text popup and highlight style/color prompt, saved-highlight/note popup actions, styles, colors and confirmations, standalone dictionary entry, fixed chrome and no-match text in the in-book dictionary popup, nested results lists, in-book editors, preset picker and action pager, fixed controls in online lookup preview/results and its topic/language editor and provider disclosure, the end-of-document action dialog and preference rows, Contents list controls and search editor, document-library chrome, folder-row status labels and Find/Sort screens, document-search editor/results headings, navigation, result-options sheet and advanced-settings list, the shared reading-settings numeric picker, and saved-mark search controls, bookmark-browser headers, Sources/Filters rows, shared color palette, book/collection/folder and property chooser controls, book information/description controls and Results/Search/mark-detail controls, and the picker title. Menu search matches both Vietnamese and English names for localized top and Pages actions, end-of-document preferences and these configuration-panel rows. It explicitly says “partial” and identifies the untranslated areas; the rest of the interface, including other numeric editors and document-search notices, saved-mark result details, many action details, deeper untranslated breadcrumb rows, unknown configuration labels, unavailable-reason and feedback messages, document-library search-result file metadata, other opened menu screens, online image viewer and shared pager, the file-deletion confirmation, other dialogs and accessibility text, remains English. Book content, selected text, dynamic notices and user-supplied names are never translated. The translations are authored for Reader, not copied from KOReader's catalog.

KOReader's [language list and language-change behavior](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/language.lua#L1) are the reference. This first increment does **not** close its Vietnamese locale parity: complete Vietnamese coverage, its other interface locales, plural/number/date handling, right-to-left mirroring, font fallback, and small-screen text-fit review remain open. The frozen screenshot control inventory records its original observations and is not a current completion claim.

The UI uses the existing shared list, icons, and reading bars; no new gesture or screen geometry is introduced. Validate language persistence, fallback from unknown values, navigation/exit, glyph coverage, text fit, dark mode, and portrait/landscape before release. No device, screenshot, or behavioral validation was performed for this increment.
