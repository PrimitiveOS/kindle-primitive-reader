# KOReader reading controls and Reader parity

Reference release is KOReader **v2026.07.1**, commit `9192014d8bd82a91dc1012473be0f238dedfdb54`. The inventory follows the tagged Lua source through menu construction, gesture dispatch, document configuration and rendering. The acceptance tests extend the [reading parity plan](reading-parity-plan.md) and [requirements](requirements.md). [Tagged release](https://github.com/koreader/koreader/releases/tag/v2026.07.1) · [KOReader user guide](https://koreader.rocks/user_guide/)

**Released** means present in published Reader 0.1.1 at `40f1f3fc3a8978039239dc5a449e1eeeeb03567e`. **In progress** means visible in the next worktree changes and awaiting integrated validation. **Open** means the equivalent still needs implementation or provider work. Publication and hardware validation are recorded separately. [Reader 0.1.1 release](https://github.com/PrimitiveOS/kindle-primitive-reader/releases/tag/v0.1.1)

## Implemented in Reader 0.1.2

| Area | Reader controls |
| --- | --- |
| Menu layout and gestures | Primitive Browser-style icon cards with four columns, persistent category labels, grouped top actions and a separate format panel. Top gestures select Navigation, the last visited group or Library by start position. The bottom gesture recalls the last format panel. Settings expose tap and swipe activation and the option to open both bars. |
| Navigation and browsing | Contents, bookmark toggle and search, forward and backward location history, previous document, a chapter and page-range map with annotation counts, thumbnail skimming that preserves the current position until a destination is chosen, and optional timed page turns. |
| Typography | Font choice, presets, type size, line spacing, independent side, top and bottom margins, actual two-page reflow, word and letter spacing, contrast and weight, alignment and hyphens, publisher CSS, kerning and hinting. Scrolling and vertical EPUB use one page. |
| Fixed-page and scan view | Fit, zoom, quarter-turn document rotation, page or continuous mode, continuous gaps, supported facing pages and reading direction, manual and auto crop, scan contrast and white level, ordered image dithering, columns, available OCR languages and bounded text reflow. |
| Screen and status | Portrait override, interface palette, explicit page-color inversion, available hardware frontlight and warmth, touch settings, full refresh and reading status options. |
| Lookup and annotations | In-book search with recent queries, typed and selected-text dictionary lookup, result source selection, lookups and vocabulary, and existing highlights and notes. |

The remaining rows below compare the 0.1.1 baseline with the tagged reference. Provider-specific gaps include physical landscape, explicit right-to-left reflow spreads, arbitrary PDF deskew with remapped annotations, and deeper scanned layout recovery. The full KOReader map, gesture assignment system, and remote translation and Wikipedia lookups have separate acceptance work.

## Bottom configuration inventory

The bottom panel takes structured definitions rather than treating every option as a menu page. `ConfigDialog:onConfigChoose` updates the option value, dispatches its event, reevaluates dependent choices, and repaints the panel. Some controls hide the overlay until a timer fires or the event handler calls back. A tab change repaints the combined old and new bounds, and closing uses a partial refresh. Press and hold can expose exact values, help or a default-setting control. `ReaderConfig` persists document options under separate reflow and fixed-page prefixes. `ReaderMenu:saveDocumentSettingsAsDefault` provides an explicit path for global defaults. [Config dispatch, repaint and numeric pickers](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/ui/widget/configdialog.lua#L950-L1384) · [Per-document persistence](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/apps/reader/modules/readerconfig.lua#L183-L197) · [Global defaults](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/apps/reader/modules/readermenu.lua#L362-L387)

Reflow changes that affect pagination preserve the source location and selection, even while page numbers change. Font gamma or a view overlay can repaint without changing glyph advances. KOReader uses optional partial rerendering and tells other modules when full pagination remains provisional. Reader should benchmark chapter rerendering and keep exact anchor resolution as its source of truth. A deferred render should discard results for a previous book, anchor or settings revision. ## Live actions, defaults and return paths

Keep draw state, editable settings and the durable location separate. A direct choice such as the current rotation or text alignment can render in place and leave the panel open. A change that paginates text or crops a complex PDF may show a progress state, update the document and reselect the same panel. Crop selection, typed input and font selection need their own focus and cancellation. Save the per-book setting only after the change succeeds. Offer a deliberate action when saving a preset or copying settings to other books. A selected choice, current-book value and global default need distinct indicators. [Reference choice dispatch](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/ui/widget/configdialog.lua#L983-L1047) · [Reading settings](../src/reading_controls.rs) · [Fixed-page session](../src/fixed_session.rs)

## Next implementation checks

1. **Overlay layout and input.** Use one synthetic EPUB and one password-free PDF on desktop and Oasis 3. Open the top menu by tap and top-edge down swipe, and the format controls by a bottom-edge up swipe. Confirm the middle scroll region, links, selection, physical buttons and page-direction setting still work. Close each overlay, run Done and Exit, and confirm the same passage on reopen. Repeat with large controls, night pages, touch lock and a page whose text runs under both overlays. Compare selection once to the local Oasis captures.
2. **Live configuration and layout.** Apply text size, spacing and page mode without losing the selected text anchor. Change PDF fit, zoom, rotation and continuous mode while retaining source page and visible area as supported. Test all controls on both available orientations and an RTL comic. Toggle visibility conditions and verify a selected value stays visible and persists only within the intended book. Measure ordinary and expensive adjustment refreshes separately.
3. **Navigation and skim.** Build Skim on the existing page/percentage jump, chapter and bookmark primitives. KOReader records the original position, previews target movements, can return to origin, and adds the origin once when committing a move. Test EPUB and PDF sequences that enter Skim, preview several targets, cancel, then repeat and commit. Validate printed PDF labels, previous/next bookmarks and chapter boundaries. [Reference Skim state transitions](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/ui/widget/skimtowidget.lua#L421-L506) · [Reader reading position](../src/library.rs)
4. **Automatic page turn.** The reference schedules a single relative movement after inactivity while the reader is the top visible widget. Input advances the next deadline, and suspend/close unschedules the task. A long press can adjust movement distance for scrolling. For Reader begin with one next-view action at a time through the existing paced handler. Test explicit start/stop and manual interaction, no catch-up after a slow render, no turn under controls or during sleep/USB, and stop at the final page. Fractional scroll distance and suspend preference are follow-up behavior. [Reference automatic turn implementation](https://github.com/koreader/koreader/blob/v2026.07.1/plugins/autoturn.koplugin/main.lua)
5. **Selection and lookup.** Verify touch and hardware navigation continue around contextual popups. Use a word with variants, overlapping highlight spans and a rotated PDF. Close lookup and check the original selection and reading anchor. Verify typed lookup, history and vocabulary offline, clear only the chosen local history, and confirm a deleted or unresolvable bookmark does not navigate to an unrelated location. [KOReader highlighting](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/apps/reader/modules/readerhighlight.lua) · [Reader dictionary](../src/dictionary.rs)
6. **Deeper provider work.** Add reflow widths/margins and PDF scan preprocessing as independent engine changes with fixture comparisons. Keep the recognized PDF words, annotations and bookmarks tied to source coordinates across updates. Extend map, reading footer and accessible gesture choices after the document controls pass the same regression suite.

Record the Reader source and ZIP digest, KOReader tag, document provider, firmware, input method, gesture result and before/after location for each device run. Keep desktop screenshots, framebuffer captures and direct physical E Ink observations distinguishable in test reports. One acceptable frame in a simulator gives separate evidence from the panel's refresh behavior on a Kindle.
