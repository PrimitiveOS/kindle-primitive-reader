# Online lookups while reading

Hold a word and use **Wikipedia** or **Translate** in the selection grid. **Search** in the top reading bar also offers a typed Wikipedia topic and translation of the current page. The preview shows the text, destination language and service. A network request starts when the reader taps Search, Translate or Full article. Closing the sheet restores the passage and selection. PDF and DjVu page translation uses the text layer or a previously recognized page. Reflow uses the lines visible in the current viewport or spread.

| Workflow | KOReader source | Reader behavior |
| --- | --- | --- |
| Encyclopedia search | The reference searches the selected Wikipedia edition for introductory extracts. It can request a full article or show history. [ReaderWikipedia](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/apps/reader/modules/readerwikipedia.lua) · [Wikipedia requests](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/ui/wikipedia.lua) | Reader searches the selected edition, orders up to three available results by rank, and offers the full article text. Previous and Next, including the physical page buttons, page through an article. Back from the full article returns to its introduction. |
| Translation | KOReader requests Google's translation service using the source language or automatic detection and the target language. Its Translation settings include an opt-in “Show romanizations” preference. [Translator](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/translator.lua) | Reader accepts language codes and can send a selected passage or a readable page to Google Translate. The saved, default-Off romanization option adds Google's `dt=rm` field and displays the source, returned Latin text and translation. The selectable MyMemory provider uses explicit language pairs and does not request romanization. A provider failure stays on the sheet. MyMemory accepts up to 500 bytes per request, so a longer passage is sent in successive pieces to the chosen provider. [MyMemory API](https://mymemory.translated.net/doc/spec.php) · [Romanization details](translation-romanization.md) |
| Selection and history | KOReader connects selection actions to external reference tools while preserving the book context. [ReaderHighlight](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/apps/reader/modules/readerhighlight.lua) | Reader runs the HTTPS request in a separate process. Cancel, document changes and sleep end a pending request. History stores up to eight successful searches or translations locally. Open **Search → Online history** to repeat a query, clear the history or turn recording off. |

Wikipedia uses the MediaWiki query API and plain-text extracts, with a versioned Reader user agent and project contact URL. Reader verifies server certificates and restricts requests to its built-in service URLs. A lookup accepts up to 6,000 bytes of text and a Wikipedia search accepts 150 characters. Very long articles report the display limit. Wikipedia images, exporting articles to EPUB, alternate translation analyses and custom server URLs remain open. Google's endpoint is the one used by the tagged reference. Its availability and rate limits are controlled by the provider. [MediaWiki search](https://www.mediawiki.org/wiki/API:Search) · [TextExtracts](https://www.mediawiki.org/wiki/Extension:TextExtracts)

## Verification

Run `cargo test --locked --lib online` and `cargo test --locked --lib selected_wikipedia`. The tests cover request encoding, URL host validation, result ordering, Unicode chunk boundaries, romanization response parsing and preference persistence, provider failures, process cancellation, touch selection, hardware pagination, local history and restoration of the reading anchor. To regenerate the following screenshots, set `PRIMITIVE_READER_LOOKUP_SCREENSHOTS` to an output directory before running the tests. The on-screen passage and provider response are synthetic fixtures. Live HTTPS checks on the Mac separately returned three Wikipedia results for “E-paper” and a MyMemory English-to-Vietnamese translation. The Google endpoint returned HTTP 429 during the live check.
