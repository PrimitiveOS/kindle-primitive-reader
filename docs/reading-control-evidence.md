# Core reading controls compared with KOReader

This audit compares the Reader 0.1.6 release candidate with KOReader v2026.07.1 at commit `9192014d8bd82a91dc1012473be0f238dedfdb54`. It covers controls used while reading. The evidence combines full 1264 × 1680 Oasis 3 reference frames, the tagged Lua handlers and the Rust paths that consume an action. Proposed acceptance checks below remain open until each passes. [KOReader menu order](https://github.com/koreader/koreader/blob/v2026.07.1/frontend/ui/elements/reader_menu_order.lua) · [Reader source inventory](koreader-source-inventory.md)

## Implementation order

1. **Selection, dictionary and note navigation.** Start with a linked note and two small dictionaries in an authored EPUB. Compare the action surface, each nested back step, the exact anchor, the selected quotation and saved result state. Repeat the selection subset on embedded PDF text and OCR.
2. **Landscape and bottom typography.** Make viewport transforms and input geometry agree before adding more controls. Compare four orientations, RTL spread order, type size, word spacing and maximum expansion using the same pages.
3. **Contents, book map and footer.** Give each consumer the same effective chapter list, test custom and publisher outlines, then add depth, chapter-length and progress preferences. Check sparse outlines and mixed front matter.
4. **Provider and system verification.** Run the path matrix on EPUB, PDF and DjVu. Capture each visible overlay using an authored book. Include callbacks, exact saved locations, framebuffer checks and separate observations for physical buttons and e-ink refresh. A screenshot alone cannot establish persistence or gesture behavior.

## Documented behaviors

The Documents picker labels unsupported formats, oversized files and recognized protected
AZW containers. Damage inside an otherwise supported publication can first become
visible on opening a chapter. An upper swipe opens the upper menu by default and can
be configured to show both bars. [Reader instructions](../README.md#reading-on-kindle)
