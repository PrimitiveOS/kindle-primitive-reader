# Fixed Book Map reading time

When reading statistics are enabled, the fixed-document Book Map shows a narrow bar in each visible slot with recorded page visits. The bar height is relative to the longest recorded slot in the current map window; a slot covering several pages sums their recorded durations. The **Reading time** caption appears only when that window has recorded visits. The display does not change statistics, reading position, map targets, saved marks, or the reading footer.

Only visits associated with a zero-based physical page of the currently open fixed document are included, whether or not a visit has a wall-clock date. Time imported without a page assignment is not placed on the map. A slot is gray when at least one of its dated visits started in the current session and is not future-dated, using the same session boundary as Reader's statistics report; otherwise it is black. A grouped slot may combine earlier and current-session visits, so gray does not mean every page in that slot was read this session. Undated visits and visits with an unknown clock or session boundary remain black unless another visit in their slot qualifies. The computation uses the existing bounded visit journal and at most 48 slot totals. Disabling statistics hides the bars. Because the scale is local to the visible window, bar heights should not be compared between map windows. Reflow-book maps remain open.

KOReader's pinned [Book Map statistics integration](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L825-L833) and [current-session shading](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L373-L395) provide the reference. Reader's grouped-slot, window-relative display is not a claim of identical per-page shading or statistics scaling. This addition has not yet been tested in simulation or on Kindle.

The fixed Book Map also shows the last three valid previous and next navigation locations as numbered filled and outlined badges. If multiple locations in the same direction fall within a grouped slot, only the most recent is shown; invalid or anchored non-fixed locations are skipped. The caption provides a legend when a visible slot contains history. These are read-only cues: map selection and the navigation stacks are unchanged. KOReader's [location-stack use](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L839-L841) and [map legend](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L1454-L1461) are the reference. Reflow-map history badges remain open; the fixed badges need simulation and Kindle validation.

The fixed map distinguishes bookmarked pages, highlighted pages and pages with notes using bookmark, marker and pencil icons. When a slot is hidden or too narrow to show both a highlight and a note, the note icon takes precedence; a bookmark remains separately indicated. The visible **Help** button opens a modal guide to map navigation and these indicators, including the time and history cues. **Done**, Back, or tapping outside returns to the unchanged map. KOReader's [mark indicators](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L495-L521) and [About view](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L1450-L1461) provide the reference. The help, cue collision behavior, translations and Kindle layout remain untested.

An upward triangle identifies the slot containing the actual reading page, separately from the selected map border and the small Page Browser focus outline. In a grouped slot the triangle identifies the containing range, not an exact page within it. It does not move the reader or alter map focus. KOReader's [current-page legend](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L1454-L1461) is the reference. The new cue still requires simulation and Kindle validation.

The visible **Return to book** control closes nested Book Map and Page Browser views and returns to the existing fixed-document reading position. **Back** still returns one level at a time, and the Help modal must be closed first. This follows the intent of KOReader's [close-parent behavior](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L1502-L1511). The new control still requires simulation and Kindle validation.
