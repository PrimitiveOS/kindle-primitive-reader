# Page Browser thumbnail numbers

The Page Browser **Grid** panel offers three **Thumbnail page numbers** modes: **None**, **Row start**, and **All**. Row start labels the first thumbnail in each visual row; All is the existing default. Thumbnail touch targets, the selected-page indicator, bookmark icons, and hidden-page indicators remain available in every mode. The original reading position is unchanged until a thumbnail is opened.

Changing the mode saves a choice for the current book. **Save number default** saves the displayed choice for books without their own choice. **Use default numbers** removes the current book's override, so it follows the Reader default again. Book settings are part of the library and follow its existing save, backup, merge, and rollback paths. The default is stored with Reader controls and follows the existing reading-backup behavior for those controls. Older data without these fields continues to show all page numbers.

KOReader's pinned [page-number modes](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/pagebrowserwidget.lua#L331-L366) and [Page Browser menu](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/pagebrowserwidget.lua#L1080-L1104) provide the reference. Reader presents labels inside its existing thumbnail controls instead of KOReader's side labels. This implementation still requires simulation, accessibility, and Kindle display and persistence validation.

For fixed-layout documents, the ribbon retains its existing whole-document mapping and chapter ticks. On eligible reflow books, opening Page Browser requests the exact whole-book screen-page index in the background. Once that index is ready, the ribbon shows a book-wide page stripe centered on the browsed thumbnail; tapping or swiping it can move focus across chapter boundaries, and the view refresh preserves the focused source page when the index arrives. If the index is unavailable or cannot be built, the existing chapter-local stripe remains available. A long hold opens Book Map for the browsed chapter. Mirrored layouts reverse the stripe. The reading position stays unchanged until a thumbnail is opened. This candidate is unverified and requires simulation, interaction, and Kindle validation.

Grid's **Chapter levels** setting and its separate custom/publisher persistence remain available. Fixed-document chapter ticks and reflow spans honor the selected depth. When whole-book screen-page data and heading locations are available, reflow headings map across the spine; each heading spans to the next equal-or-shallower heading, clips at the visible stripe edges, and shows its title when the span has room. Deeper sections occupy separate compact lanes. Span borders align with page-slot edges; page indicators remain centered in their slots, and mirrored layouts reverse the same geometry. Opening Page Browser requests saved custom Contents, bookmark, recent-history, and canonical highlight endpoint targets along with the whole-book page index. That worker resolves anchors in their own spine chapters, including chapters outside the one currently open, then the stripe uses those exact page locations. Raw, stale, suppressed, or unsupported targets remain unknown; when the index is unavailable the local spans and saved page positions are the fallback. Cross-chapter anchor handling now has an authored regression workflow but still needs execution, stock geometry comparison, screenshots, and Kindle appearance validation. KOReader's Page Browser configures the selected depth and its Book Map row draws titled ranges across the pages they cover ([depth control](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/pagebrowserwidget.lua#L1053-L1078), [span rendering](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L173-L275)).

The ribbon handle identifies the browsed page and a separate caret indicates the actual reading page when it is in the displayed stripe. Up to three previous and next locations are marked where they resolve within it. With the whole-book page index, saved page locations and canonical bookmark/history anchors can be marked across chapters. The index resolves each anchor against its own spine chapter, so ribbon marks follow rendered pages after repagination. If the index is unavailable, local canonical anchors or saved page positions provide the fallback; raw or unresolved anchors may be omitted. Nearby cues can overlap and none changes saved history or reading position. Fixed-page cues retain their existing behavior. KOReader's Page Browser reloads bookmarked pages and supplies them to the shared Book Map row ([bookmark retrieval](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/pagebrowserwidget.lua#L207-L215), [Book Map indicators](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/bookmapwidget.lua#L35-L85)).

On the ribbon, gray marks indicate highlights, black marks indicate notes, and taller black marks indicate page bookmarks. With the exact whole-book index, canonical highlight endpoints map to book-wide screen pages; the exclusive end is biased to the preceding page at an exact page boundary. Same-chapter spans require ordered endpoints; cross-chapter spans also require the existing background worker to verify the saved quote before they appear. The visible portion of a verified span is marked across the ribbon. Raw, stale, reversed, pending, and unverifiable selections are omitted. If the whole-book index is unavailable, resolvable same-chapter selections use the loaded chapter layout. Page-based bookmarks and history locations can map across chapters. At most 512 saved marks are examined, with a shared per-draw estimate of line, block and element work also limiting anchor resolution. Later or unverifiable cues may be omitted, especially in large chapters. This is an estimated work cap, not a measured device latency bound. Fixed-page cues retain their existing behavior.

The existing cancellable position-verification worker continues to support thumbnail cues and verifies cross-chapter highlight quotes before drawing their ribbon spans. Raw-position ribbon cues are omitted from the local reflow stripe.

Thumbnails show a highlight icon on pages containing a saved highlight, or a note/edit icon when any highlight on the page also has a nonblank note. Fixed documents include continuation pages of multi-page selections. Reflow documents use the existing current or preview chapter layout and mark pages where a verified selection produces visible geometry; unresolvable anchors are skipped. To bound work on heavily annotated books, at most 512 reflow page/selection geometry checks are performed per draw, so later marks may be omitted from that thumbnail window. The existing bookmark indicator remains in the opposite corner, and thumbnail tap and hold actions are unchanged. This Reader-specific thumbnail cue was inspired by KOReader's highlight and note indicators on the page ribbon. Exact KOReader ribbon symbols and broader reflow cue coverage remain open, and the new cues still need simulation and Kindle validation.

For a canonical or raw highlight crossing chapter boundaries, the worker verifies the complete saved quote before the current thumbnail chapter may display a local fragment. It requires a verified source and font snapshot, unique chapter paths and no unsupported or recovered-placeholder chapters; unresolvable or empty chapter fragments are omitted. The visible local fragment is mapped from the current preview layout without changing the reading position or saved mark. The same worker authorizes cross-chapter ribbon spans. Each Page Browser verification job checks at most four eligible cross-chapter selections for the focused chapter, with a maximum span of eight chapters; failed, pending, or over-limit selections remain omitted. The worker checks cancellation between chapter layouts, enforces the saved-highlight text limit, and preserves ODT continuation separators. These changes need simulation and device validation.

The Grid panel's **Help** button explains the implemented thumbnail, page-button, edge-swipe and ribbon controls, visual cues, and settings. Back returns to Grid without changing the book or browser position. This follows the intent of KOReader's [Page Browser About and gestures help](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/pagebrowserwidget.lua#L1145-L1207); Reader's text describes its own behavior. The layout and translations still require simulation and Kindle validation.

The visible **Return to book** button closes the Page Browser and any nested Book Map/Page Browser stack, returning to the existing reading location rather than opening the browsed thumbnail. **Back** retains its normal one-level navigation. KOReader supports [closing parent browsers together](https://github.com/koreader/koreader/blob/9192014d8bd82a91dc1012473be0f238dedfdb54/frontend/ui/widget/pagebrowserwidget.lua#L1209-L1220); Reader exposes a separate touch control for this action. The new control still requires simulation and Kindle validation.
